# Technology Stack: AI Tool Directory

## Core Framework & Language
- **Next.js 14 (App Router):** Chosen for its performance, SEO capabilities, and robust developer experience.
- **TypeScript:** Ensuring type safety and maintainability across the codebase.

## Frontend & UI
- **Tailwind CSS:** For rapid, utility-first styling.
- **UI Component Libraries:**
    - **Shadcn UI:** Core accessible components.
    - **Magic UI & Aceternity UI:** High-quality animations and complex visual components.
    - **Framer Motion:** Smooth, physics-based animations for a premium feel.
- **Recharts:** Powering the interactive and explorable tool comparison charts.

## Backend & Infrastructure
- **Prisma (ORM):** Providing a type-safe interface for database operations.
- **MongoDB:** Flexible document store suitable for varying tool metadata and community reviews.
- **Clerk:** Seamless and secure user authentication and management.

## State Management & Utilities
- **React Hook Form & Zod:** Robust form management and schema-based validation.
- **Lucide React:** Consistent and modern iconography.
