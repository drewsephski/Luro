## 🌟 Introduction
VoiceFlow is an innovative voice agent platform designed to help you build and deploy AI-powered voice applications effortlessly. Built with Next.js, Tailwind CSS, Shadcn UI, Magic UI, Aceternity UI, Prisma, MongoDB, Clerk, React Hook Form, and TypeScript, VoiceFlow provides powerful voice AI integration and user-friendly features to create advanced conversational experiences.

## 🚀 Features

- Real-time voice agent monitoring and analytics
- Natural language processing and understanding
- Voice synthesis and audio processing
- Custom voice agent creation and deployment
- Advanced conversation flow management

## 🛠️ Installation
To run VoiceFlow locally, follow these steps:

1. Clone the repository:
    ```bash
    git clone https://github.com/Shreyas-29/voiceflow.git
    ```
2. Install dependencies:
    ```bash
    pnpm install
    ```
3. Set up environment variables in a `.env` file:
    ```
    # app
    NEXT_PUBLIC_APP_NAME=
    NEXT_PUBLIC_APP_DOMAIN=

    # database
    DATABASE_URL=

    # auth
    NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=
    CLERK_SECRET_KEY=
    NEXT_PUBLIC_CLERK_SIGN_IN_URL="/signin"
    NEXT_PUBLIC_CLERK_SIGN_UP_URL="/signup"
    NEXT_PUBLIC_CLERK_SIGN_IN_FALLBACK_URL="/"
    NEXT_PUBLIC_CLERK_SIGN_UP_FALLBACK_URL="/"
    ```

4. Run the development server:
    ```bash
    pnpm run dev
    ```
